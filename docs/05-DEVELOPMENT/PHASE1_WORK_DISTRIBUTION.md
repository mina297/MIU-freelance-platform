# MIU Freelance Platform
## Phase 1 — Frontend Work Distribution

**Team:** 5 Members  
**Technology:** React, Vite, Tailwind CSS, React Router  
**Scope:** Frontend development using mock data

### Responsibilities

- Project setup and folder structure
- Routing and page layouts
- Login and registration
- Password reset
- Role-based access and navigation
- Identity verification interface (Face + ID)
- AI chatbot interface
- Notifications
- Shared application/session foundation

### Main Deliverables

- Working frontend foundation
- Authentication screens
- Verification demonstration
- Role-aware navigation
- Chatbot and notification interfaces

## Member 2 — Freelancing Marketplace

### Responsibilities

- Browse and search projects
- Project details and job posting
- Submit and manage proposals
- Proposal comparison and selection workflows
- Browse, create, and manage services
- Service packages and extras
- Service orders and delivery tracking
- Freelancer search
- AI skills matching interface

### Main Deliverables

- Projects and proposals workflow
- Services marketplace workflow
- Order and delivery screens
- Skills matching demonstration

---

## Shared Development Rules

All members should:

- Follow the approved Figma design.
- Use reusable React components.
- Support desktop, tablet, and mobile web layouts.
- Use realistic and consistent mock data.
- Display all financial amounts in EGP.
- Test assigned pages before integration.
- Follow the agreed GitHub workflow.
- Coordinate changes to shared files and contracts.
- Update relevant documentation when functionality changes.

## Integration Responsibilities

- Each member maintains their assigned modules.
- Shared components should have one primary owner.
- Feature modules should use agreed data structures.
- Pull requests should be reviewed before merging.
- Team members should jointly test complete user journeys.

## Phase 1 Boundary

Phase 1 uses simulated authentication, AI, identity verification, payment, and escrow workflows.

Backend integration and production services are planned for later phases.
